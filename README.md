# 내 투자 노트 (1단계)

내 자산 + 종목 리포트(실제 시세) + 규칙 화면이 있는 앱이에요.
보유 종목은 내 구글 시트에 저장돼요. 구글 시트 연결 전에는 **데모 모드**로 열려요(저장 안 됨).

## 전체 순서 (약 30~40분, 한 번만 하면 돼요)

- A. 구글 시트 + 저장 코드 붙이기 (10분)
- B. GitHub에 파일 올리기 (10분)
- C. Streamlit Cloud에 올리고 비밀 설정 넣기 (10분)
- D. 폰 홈 화면에 추가

돈이 오가는 계정(증권사 ID/비밀번호, API 키)은 이 앱에 전혀 필요 없어요.

---

## A. 구글 시트 + 저장 코드

1. 구글 시트를 새로 만들어요. 이름은 `투자노트 데이터` 같은 아무 이름이나 괜찮아요.
2. 메뉴 `확장 프로그램 > Apps Script`를 열어요.
3. 기존 코드를 모두 지우고 `Code.gs` 파일 내용을 통째로 붙여넣고 저장해요.
4. 왼쪽 톱니바퀴 `프로젝트 설정`을 누르고, 아래쪽 `스크립트 속성`에서 `스크립트 속성 추가`를 눌러요.
   - 속성: `TOKEN`
   - 값: 아무도 모를 긴 문자열(영문+숫자 30자 이상). 메모장에 따로 적어두세요. 아래 C단계에서 또 써요.
5. 오른쪽 위 `배포 > 새 배포`를 눌러요.
   - 유형 선택(톱니바퀴): `웹 앱`
   - 다음 사용자 인증 정보로 실행: `나`
   - 액세스 권한이 있는 사용자: `모든 사용자`
   - `배포`를 누르고, 처음 한 번 `액세스 승인`을 해줘요(안전하지 않다는 안내가 나오면 `고급 > 이동`).
6. 나오는 `웹 앱 URL`(https://script.google.com/macros/s/…/exec)을 복사해서 메모장에 적어두세요.

> 이 주소는 TOKEN 없이는 아무것도 읽거나 쓰지 못해요. 그래도 주소와 TOKEN은 남에게 알려주지 마세요.
> 나중에 Code.gs를 고치면 `배포 > 배포 관리 > 연필 > 새 버전`으로 다시 배포해야 반영돼요.

## B. GitHub에 파일 올리기

1. github.com에서 무료 계정을 만들어요.
2. 오른쪽 위 `+ > New repository`를 눌러요.
   - 이름: `stock-note`
   - **Private(비공개)** 선택, `Create repository`
3. 만들어진 화면에서 `uploading an existing file` 링크를 눌러요.
4. 아래 5개 파일을 끌어다 놓고 `Commit changes`를 눌러요.
   - `app.py`, `market.py`, `signals.py`, `store.py`, `requirements.txt`
   - `Code.gs`와 `README.md`는 올리지 않아도 돼요.

## C. Streamlit Cloud에 올리기

1. share.streamlit.io에 접속해서 GitHub 계정으로 로그인해요.
2. `Create app`(또는 `New app`) > GitHub 저장소 `stock-note`, 브랜치 `main`, 파일 `app.py` 선택해요.
3. 배포하기 전에 `Advanced settings > Secrets` 칸에 아래 내용을 붙여넣고 값을 바꿔요.

```
APP_PASSWORD = "내가 정한 앱 비밀번호"
GAS_URL = "A단계 6번에서 복사한 웹 앱 URL"
GAS_TOKEN = "A단계 4번에서 정한 TOKEN"
```

4. `Deploy`를 눌러요. 처음에는 몇 분 걸려요.
5. 앱 설정에서 공개 범위를 확인하세요. 저장소를 Private으로 만들었으면 비공개 앱으로 쓸 수 있고(무료 계정은 비공개 앱 1개), 이 앱은 비밀번호 화면도 따로 있어요.

## D. 폰에서 쓰기

폰 브라우저로 앱 주소를 열고, 메뉴에서 `홈 화면에 추가`를 누르면 앱처럼 쓸 수 있어요.

---

## 처음 쓰는 순서

1. 앱을 열고 비밀번호를 입력해요.
2. `내 자산` 아래쪽 `보유 종목 편집`에서 보유 종목을 입력하고 `저장`을 눌러요.
   - 증권사 / 종목코드(6자리) / 종목명 / 꼬리표(중장기·스윙) / 수량 / 평균단가
3. 카카오 소수점 정기매수는 종목명 / 티커(NVDA) / 하루금액 / 시작일을 입력해요.
4. 구글 시트를 열어보면 `보유종목`, `정기매수` 탭이 생겨 있어요. 시트에서 직접 고쳐도 돼요.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "시세를 가져오지 못했어요" | 종목코드 6자리 확인. 잠시 뒤 `시세 새로고침`. 무료 시세 출처가 일시적으로 막히는 경우가 있어요 |
| "구글 시트에서 불러오지 못해서 저장을 막았어요" | GAS_URL·GAS_TOKEN 확인. Apps Script 배포가 `모든 사용자` 접근인지 확인 |
| 비밀번호 설정 안내가 뜸 | Secrets에 APP_PASSWORD를 넣었는지 확인 |
| 데모 모드라고 나옴 | Secrets에 GAS_URL과 GAS_TOKEN이 둘 다 있는지 확인 |

## 이 단계에서 되는 것 / 아직 안 되는 것

- 되는 것: 증권사별 합산, 종목별 수익률, 쏠림 경고, 가격 기준 신호(손절선·목표·20일선·RSI·눌림목), 종목 차트, 카카오 정기매수 추정 계산
- 아직 없는 것: 재무·안전 기준(DART), 수급, 증권사 리포트, 종목 발굴, 매매일지, 규칙 저장, 알림
